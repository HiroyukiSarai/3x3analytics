# 3x3バスケットボール戦術分析システム - 開発計画

## 🎯 最終目標

1. **プレーの切り出し** - ボールチェック→シュートまでを1プレーとして抽出
2. **2D軌跡の可視化** - 選手6人の動きを真上から見たコート図で表示
3. **パターン分析** - 似たプレーをグループ化、頻度順に表示
4. **動画との紐付け** - 該当プレーの動画クリップも見られる

---

## 📋 開発フェーズ

### Phase 1: シンプル版（MVP）⭐ 現在ここ

**目標**: 確実に動く最小限の機能

| # | タスク | 状態 |
|---|--------|------|
| 1-1 | ROI（コート領域）設定 | 🔄 |
| 1-2 | 選手検出（YOLO） | 🔄 |
| 1-3 | 基本トラッキング | 🔄 |
| 1-4 | 2Dコート表示 | 🔄 |
| 1-5 | 軌跡の記録・表示 | 🔄 |

**シンプル版の仕様**:
- 動画をアップロード/パス指定
- 四角形でコート領域を囲む（ROI）
- ROI内の選手のみ追跡
- ROI座標を2Dコート座標に線形変換
- 軌跡を2Dコートに表示

## 🔧 技術スタック

| 用途 | ツール |
|------|--------|
| 検出 | YOLO11 (Ultralytics) |
| トラッキング | BoxMOT (ByteTrack/BoT-SORT) |
| 座標変換 | OpenCV (cv2.getPerspectiveTransform) |
| 可視化 | Plotly |
| UI | Streamlit |
| パターン分析 | DTW + scikit-learn |
